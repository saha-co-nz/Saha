# Official Repository for the [Saha Website](https://www.saha.co.nz)

## Tech Stack:
<ul>
  <li>
    Frameworks: React, Next.js
  </li>
    <li>
    Frontend: TypeScript w/ TailwindCSS
  </li>
    <li>
    Backend: PayloadCMS connected to Supabase (PostgreSQL)
  </li>
    <li>
    Hosting: Vercel, AWS S3
  </li>
</ul>
